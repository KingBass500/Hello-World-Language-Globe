# Hello World Language Globe

A colorful animated globe made from "Hello, World!" greetings in a wide selection of languages and scripts. Drag to rotate, pause/resume, adjust speed, shuffle the greetings, and search by language or phrase.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `hello_world_language_globe` folder in Visual Studio Code.
3. Open `index.html` in your browser. You can also install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.
4. No npm install, server code, or external libraries are required.

## Add another language
Open `script.js` and add an item to the `greetings` array using this format:

```js
["Language name", "Hello, World! translation"],
```

## Note
The globe includes a broad selection of languages, but it does not claim to include every language in the world. There are thousands of living languages and some have multiple dialects, scripts, or competing translations. Add verified translations to expand it.
